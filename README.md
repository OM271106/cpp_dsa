# C++ Data Structures and Algorithms (DSA)

This repository contains my personal implementations of Data Structures and Algorithms in C++. 
It serves as a continuous tracker of my coding journey and a technical portfolio of my problem-solving skills as I build my foundation in software engineering.

## 🚀 Focus Areas

*   **Data Structures:** Arrays and Hashing.
*   **Algorithms:** Sorting algorithms and a deep dive into **Recursion**.
*   **Concepts:** Time and Space Complexity Analysis, foundational mathematics for competitive programming, and pattern generation.

## 📂 Repository Structure

```text
cpp_dsa/
```

## 🛠️ Local Environment & Setup
All code in this repository is written and tested using Visual Studio Code (VS Code).

My local workspace utilizes a custom configuration within the .vscode folder to automate the compilation and execution of C++ programs.
It is specifically set up to seamlessly use file-based input/output via input.txt and output.txt for streamlined debugging and competitive programming practice.
